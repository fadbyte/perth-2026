URL Scraper

Paste a list of URLs, pull the fields you want from each page, export as CSV. Tuned for sgCarMart used-car pages; works on other sites with custom fields.

Listing/search pages are expanded: every car link found on them is added to the queue.

Field syntax

Name = Label | Other label finds that label on the page and takes the text right after it.
Name = css: h1.title takes the text of a CSS selector (css: a.dealer @href for an attribute).
Name = re: (\d+) km runs a regex over the page text (first capture group).
Name = meta: og:title reads a meta tag.  Name = jsonld: offers.price reads JSON-LD.

How to load the pages

A web page isn't allowed to read another site's pages directly, so pick one of these ways around it.

  1. Drag this button to your bookmarks bar (once): Send page to scraper
  2. Press Start. The first URL opens in a new window.
  3. When the page has loaded, click the bookmark. The data is sent back here and the window moves on to the next URL by itself.

The page loads in your own browser, so it behaves exactly like a normal visit. If the bookmark says "Copied", use the Paste button on that row instead.

Public proxies see the URLs you fetch and are often blocked by sites with bot protection. If rows come back "blocked", switch to the bookmarklet method.
